AUTOMATED TEST

Failure → Failover → Recovery

The dedicated GitHub Actions workflow validates that the backup application can continue serving requests when the primary Node.js backend becomes unavailable.

  1. 01 Verify primary application and database
  2. 02 Stop the App-1 Node.js container
  3. 03 Nginx routes traffic to App-2
  4. 04 Verify database access through backup
  5. 05 Restore App-1 and verify recovery
