01

NORMAL STATE

Nginx forwards requests to the Node.js application running locally on App-1.

02

CONTROLLED FAILURE

The failover workflow stops only the App-1 Node.js container to simulate an application failure.

03

BACKUP ROUTE

Nginx detects that the primary application is unavailable and forwards requests to App-2 over its private VPC address.

04

RECOVERY

The workflow starts the App-1 container again and verifies that the application and database connection recover.
