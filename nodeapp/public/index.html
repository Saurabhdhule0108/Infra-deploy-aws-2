01 / THE PROJECT

FROM CODE TO CLOUD.

This project demonstrates the complete engineering path from source code to automated AWS infrastructure, container delivery, application routing, failover testing and persistent database communication.

01
INFRASTRUCTURE AS CODE

Infrastructure is not manually rebuilt. It is described.

Terraform represents the VPC, networking, security groups, EC2 application servers, Amazon ECR and Amazon RDS as infrastructure configuration.

01 TERRAFORM
TF

Infrastructure as Code

Terraform compares the infrastructure configuration with AWS and applies the required changes.

$ terraform plan → terraform apply
02 AUTOMATION
CI

GitHub Actions

A push triggers the deployment workflow, infrastructure operations, Docker delivery and verification.

03 IDENTITY
ID

OIDC + STS

GitHub obtains temporary AWS credentials through OIDC federation and AWS STS instead of storing long-lived AWS access keys.

04 CONTAINERS
DK

Docker + ECR

The Node.js application becomes a Docker image, is stored in Amazon ECR and is deployed to both EC2 application servers.

05 DATA
DB

Private RDS

Amazon RDS MySQL remains private and accepts database traffic from the application security group on port 3306.

08 / DEPLOYMENT JOURNEY

PUSH. BUILD. RUN.

The deployment workflow coordinates infrastructure, compute, database availability, containers, networking and verification.

01
SOURCE

Push code

A push starts the GitHub Actions deployment workflow.

02
IDENTITY

Authenticate

GitHub OIDC and AWS STS establish temporary AWS credentials through the IAM role.

03
IaC

Terraform

Terraform initializes, validates, plans and applies required AWS infrastructure changes.

04
DATABASE

Prepare RDS

The workflow ensures the RDS instance is available before application verification.

05
COMPUTE

Prepare EC2

Both application instances are started when required and checked before deployment.

06
CONTAINER

Build image

GitHub Actions builds the application Docker image.

07
REGISTRY

Push to ECR

The Docker image is stored in the project's Amazon ECR repository.

08
DEPLOY

Run containers

Both EC2 servers run the same Node.js container on port 8080.

09
ROUTING

Configure Nginx

App-1 Nginx routes to local App-1 first and App-2 as its backup application upstream.

10
VERIFY

Test everything

The workflow verifies application routing, internal connectivity and database access.
